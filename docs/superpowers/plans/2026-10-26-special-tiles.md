## 实施裁定

- 使用应用已创建的隔离 worktree；AudioSamples、Tools/AudioPrototype 是已有未跟踪内容，不修改。
- 关卡包嵌入特殊格配置快照及版本并纳入哈希，确保修改配置资产不会改变已烘焙关卡的行为。
- 手工覆盖可改变最终特殊格数量；自动布局仍严格按密度生成，覆盖后验证安全约束，不要求最终数量仍等于自动数量。
- 冲刺等级默认权重在每档允许的两级间采用 50/50；级别限制仅为默认，策划可显式修改。
- 配置 ID 必须为正且同类型内唯一；等级数量可扩展，非法参数阻断烘焙。

## 实施取舍的影响

- 用户已选择新建分支、推送并创建面向 `main` 的 PR；不执行合并，隔离 worktree 保留用于后续审查。已有 AudioSamples、Tools/AudioPrototype 不纳入提交。
- 配置快照带来包体少量重复；换取已烘焙版本的确定性，配置调整须发布新版本。
- 覆盖允许改变最终特殊格数量；若策划需要严格数量，应主动检查预览，安全限制仍强制。
- 冲刺双等级 50/50 是未指定权重时的默认裁定；若节奏不合适可逐关改权重。
- 等级正 ID 唯一校验会拒绝 0/重复 ID，避免普通格含义或历史 ID 被歧义覆盖。
- 发布包不可原地覆写，避免破坏旧版本；再次烘焙须提升包版本。
